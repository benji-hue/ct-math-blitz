# Запуск «Крока» в Telegram: пошагово

Понадобится: аккаунт Telegram, бесплатный аккаунт Cloudflare, Node.js 22 и
около 20 минут. Компьютер нужен один раз — дальше можно деплоить из GitHub Actions.

## 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → имя («Крок») и
   username (например `krok_ct_bot`).
2. Сохраните **токен** — это секрет, никуда его не публикуйте.

## 2. Подготовить Cloudflare

```bash
npm install                 # зависимости мини-аппа
npm run worker:install      # зависимости воркера
cd worker
npx wrangler login          # откроется браузер, войдите в Cloudflare
npx wrangler d1 create krok # создаст базу и выведет database_id
```

Вставьте `database_id` в `worker/wrangler.jsonc` и примените схему:

```bash
npm run db:init
```

## 3. Секреты

```bash
npx wrangler secret put BOT_TOKEN        # токен из BotFather
npx wrangler secret put WEBHOOK_SECRET   # любая длинная случайная строка, например: openssl rand -hex 32
```

Необязательно — если есть легальный доступ к внешней модели:

```bash
npx wrangler secret put GEMINI_API_KEY   # затем AI_PROVIDERS = "gemini,workers-ai"
# или любой OpenAI-совместимый API (DeepSeek, OpenRouter, Groq…):
npx wrangler secret put OPENAI_API_KEY   # плюс OPENAI_BASE_URL и OPENAI_MODEL в vars
```

Без этих ключей всё работает на Cloudflare Workers AI.

## 4. Деплой

Из корня репозитория:

```bash
npm run worker:deploy
```

Команда соберёт мини-апп и опубликует воркер. В конце будет адрес вида
`https://krok.<ваш-аккаунт>.workers.dev`. Впишите его в `MINI_APP_URL` в
`worker/wrangler.jsonc` и повторите `npm run worker:deploy` — так кнопки бота
будут открывать приложение.

## 5. Настроить бота

```bash
BOT_TOKEN=… WEBHOOK_SECRET=… APP_URL=https://krok.<ваш-аккаунт>.workers.dev npm --prefix worker run bot:setup
```

Скрипт поставит вебхук, кнопку меню «Открыть Крок», команды и описание.

Чтобы приложение открывалось и из профиля бота, и по ссылке
`t.me/<бот>?startapp`: BotFather → ваш бот → **Bot Settings → Configure Mini
App** → включить и указать тот же адрес.

## 6. Проверка

1. Откройте бота → `/start` → «Открыть Крок».
2. Пройдите онбординг, решите пару заданий.
3. Вкладка «ИИ» → задайте вопрос — ответ должен печататься по мере генерации.
4. Напишите боту вопрос текстом — придёт короткий ответ.
5. `https://<адрес>/api/ai/status` покажет подключённые модели.

## Деплой из GitHub без компьютера

1. Cloudflare → My Profile → API Tokens → шаблон **Edit Cloudflare Workers**
   (добавьте права на D1).
2. GitHub → Settings → Secrets and variables → Actions:
   секреты `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`; переменная
   `VITE_BOT_USERNAME` (имя бота без @) — для кнопки «Пригласить друга».
3. Actions → **Deploy to Cloudflare** → Run workflow.

## Версия на GitHub Pages (PWA)

Workflow `pages.yml` публикует приложение на GitHub Pages при пуше в `main`.
Чтобы там работал ИИ, задайте переменную репозитория `KROK_API_BASE` (адрес
воркера) и добавьте адрес Pages в `ALLOWED_ORIGINS` воркера. Вне Telegram
запросы к ИИ без подписи отклоняются, пока не включён `ALLOW_ANONYMOUS`.

## Локальная разработка

```bash
npm run dev                      # только интерфейс, http://localhost:5173
cd worker && cp .dev.vars.example .dev.vars
npm run db:init:local && npm run dev   # воркер с заглушкой ИИ, http://localhost:8787
```

## Чек-лист перед защитой

- [ ] Профиль → «Демо-профиль для показа»: заполненная статистика, серия,
      прогноз. Ваш настоящий прогресс вернётся при выходе из демо.
- [ ] Проверьте ИИ на площадке. Если сеть плохая, в демо-режиме приложение
      покажет заранее заготовленные ответы (они помечены «демо»).
- [ ] Показ с ноутбука в браузере: временно `ALLOW_ANONYMOUS = "true"`
      (лимиты для анонимов строже), после защиты верните `false`.
- [ ] Заряженный телефон, запасной хотспот, видео-запись демо на крайний случай.
