§ 9.График квадратичной функции

Функцию вида y = ax2 + bx + c, где a ≠ 0, называют квадратичной. Её график — парабола. Если a > 0, ветви параболы направлены вверх, если a < 0 — вниз.

Абсцисса вершины параболы: x0 = −b / (2a). Ордината вершины: y0 = y(x0). Прямая x = x0 — ось симметрии параболы.

Пример 1. Найдём вершину параболы y = x2 − 4x + 3.

Здесь a = 1, b = −4. Тогда x0 = −(−4) / (2 · 1) = 2, y0 = 22 − 4 · 2 + 3 = −1. Вершина — точка (2; −1), ось симметрии — прямая x = 2.

Так как a = 1 > 0, ветви направлены вверх, и наименьшее значение функции равно −1.
